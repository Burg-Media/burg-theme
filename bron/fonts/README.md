# Fonts for rendering the background

`ntp.html` uses two fonts. Only Geist Mono is included here.

- **Geist Mono** (`geist-mono-latin.woff2`) and **Geist** (`geist-latin.woff2`): SIL Open Font License 1.1, see `LICENSE-Geist-OFL.txt`.
- **Clash Display** (the BURGMEDIA wordmark) is **not included**: its license (ITF Free Font License) does not allow redistribution. To render the background yourself, download Clash Display from https://www.fontshare.com/fonts/clash-display and place the Semibold and Bold files here as `clash-display-600.woff2` and `clash-display-700.woff2`.

The finished images in `images/` already contain the rendered wordmark, so you only need this to change the background.
